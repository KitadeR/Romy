# 有名な観光地の一覧（sights.json）

行き先の検索に使う、日本の有名な観光地の一覧を作るスクリプト（GitHub Issue #2）。出力は `Romy/Resources/Data/sights.json`。

## 作り直し方（年に1回くらい）

```
python3 -I Tools/sights/build_sights.py
```

- 途中の結果は `Tools/sights/.cache/` に保存される（Gitには入れない）。最初から取り直すときは、このフォルダを消してから実行する。
- 初回はWikidataの候補集め（数分）と閲覧数の取得（約20分）、仕上げ（約20分）がかかる。
- 結果の要約は `last_build_report.txt` に出る。上位の顔ぶれと、閉鎖で外したもの・市区町村が1つに決まらないものを目で確かめる。

## 出どころ

| 何 | どこから | 決まり |
|---|---|---|
| 観光地・別名・読み・位置・市区町村 | Wikidata | CC0 |
| 有名さ（直近60日の閲覧数） | 日本語版Wikipedia（MediaWiki API） | 閲覧数のデータはCC0 |
| 読み（Wikidataに無いとき） | 日本語版Wikipediaの冒頭の括弧 | 本文はCC BY-SA。読みだけを使う。アプリの「データの出どころ」に書く |
| 読み（どれにも無いとき・別名） | macOSの日本語の読み推定（`reading.swift`） | — |
| 市区町村の名前 | アプリに入れた総務省の団体コードの一覧（`municipalities.json`） | — |

## 決めたこと（2026-10-15）

- 種類は博物館・美術館まで広く入れ、閲覧数で上位2,500件に絞る。
- 閉鎖日がある施設（テーマパーク・動物園・水族館・博物館・美術館・タワー・スキー場）は外す。城・寺などは「壊された日」が入っていても再建されて開いているので外さない。
- 1件ずつの閲覧数（1年分）は12,000件でHTTP 429になったため、50件ずつ取れる直近60日の閲覧数を使う。季節で順位が少し動く。

## わかっている弱点

- 話題で閲覧数が多いだけの場所も入る（印旛沼・南鳥島・沖ノ鳥島など）。
- 閉鎖日が登録されていない閉園施設は残る（甲子園阪神パーク）。
- 読み推定は伸ばす音を「い」「あ」で書く（すかいつりい）。頭の部分で合えば見つかる。
