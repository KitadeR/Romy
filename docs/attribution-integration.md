# アプリへの出典表示の組み込み手順

2026年10月29日時点の準備資料です。ファイルは文書下書きブランチへ保存済みで、開発中のアプリコードへの統合・新しいファイルを含むビルド・画面での表示確認はまだ行っていません。

## 用意したファイル

- [RomyAttributions.txt](../Romy/Resources/Acknowledgements/RomyAttributions.txt)：利用者向けのフォント・データの出典、加工内容、公式URL、2つのフォントの著作権表示とOFL原文全文。
- [RomySourceArticles.csv](../Romy/Resources/Acknowledgements/RomySourceArticles.csv)：2,500件のWikidata ID・Wikipedia記事名・元記事URL・Wikidata URL。アプリ内で元記事を開ける一覧の入力として使えます。
- [取得・加工の記録](data-sources.md)：確認の根拠と、個別の読みの出所等、確認が残る点。

## 開発側で行うこと

1. 文書下書きの変更を、提出するアプリのソースと統合します。現在のローカル開発ブランチをこの資料のために切り替える必要はありません。
2. 新しいTXTとCSVがビルド成果物に含まれることを確認します。Bundle.mainの検索名はRomyAttributions（txt）とRomySourceArticles（csv）を想定していますが、実際のコピー先で確認します。
3. 利用者が開ける「出典とライセンス」の画面に、TXTと元記事一覧への入口を設けます。設定・このアプリについて等のどこに置くかは、本人と画面構成を確認して決めます。未採用の導線を実装済みとは記載しません。
4. 各記事はCSVのwikipedia_urlから、Wikidataはwikidata_urlから開けるようにします。CSVはヘッダーあり、引用符で囲まれた値とカンマのエスケープを扱える形で読み取ります。

## 表示・同梱の確認項目

- [ ] TXTがUTF-8として読め、2つのフォントの著作権表示とOFL全文を末尾まで閲覧できる
- [ ] 元記事一覧が2,500件あり、文字を大きくしても読める
- [ ] 索引の名称・URLが元のID対応表と一致し、記事の履歴から寄稿者を追える
- [ ] 元ページを開く操作以外では、出典表示のための外部通信が発生しない
- [ ] 戻る操作、VoiceOver、文字サイズ、長い文の折り返しを確認する
- [ ] 提出するArchiveまたは配布用成果物にもTXT・CSV・OFL原文が入っている

既存の開発用アプリにOFL原文2つが入っていることは確認済みです。それだけでは、新しく用意したTXT・CSVや閲覧画面まで提出版に含まれることの確認にはなりません。

## 文書側に残す確認

個々のWikipedia由来の読みの権利範囲・追加条件と加工データの再配布表示の確認は、[出典記録](data-sources.md)で管理します。この画面用ファイルを用意したことで、その確認やアプリへの組み込みがすべて完了したとは扱いません。
