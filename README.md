# Romy（ロミー）

**旅をもっと楽しく、もっと笑顔に。**

旅行の計画・準備から旅行中の行動までを支えるiOSアプリです。Romy Nowでは、現在地・そのときの状態・旅程から過ごし方を比較し、変更内容を確認して同じ旅程へ反映できます。

作者：北出琉和。企画・画面設計・実装・動作確認を行った個人開発作品です。

## 動作環境

- macOS 27／Xcode 27.1
- iOS 27.0以降のiPhoneまたはiPhone Simulator
- Swiftコンパイラ6.4、プロジェクトの言語モードはSwift 5
- アプリはSwiftUIとApple標準フレームワークで構成。追加の外部パッケージ導入は不要です。

## 起動・確認手順

1. ソース一式を取得し、ルートの `Romy.xcodeproj` をXcodeで開きます。
2. Schemeに `Romy`、実行先に対応するiPhone Simulatorを選んでRunします。実機で実行する場合は、ご自身のSigning Teamを設定してください。
3. 行き先・日付・旅行名を設定して旅行を作成します。日付は「今日」からにすると旅行中のホームを確認できます。
4. 予定や宿を追加し、ホーム・旅程・行きたい・準備を切り替えて確認します。

**検索AIのAPIキーや中継サーバーを用意せずに、旅行作成・旅程管理・Romy Nowの案の比較、変更確認、反映・取り消し、出典表示を操作できます。** 場所検索・徒歩経路取得・Look AroundとAppleの場所カードにはインターネット接続が必要です。現在地を使う場合は位置情報の利用を許可してください。

### Romy Nowを試す

旅行中のホームの「いまどうする？」から開きます。日中に、現在の予定と、まだ先の宿・固定予定を登録すると、旅行中に過ごし方を選ぶ流れを確認できます。

1. 今日から1泊の旅行を作成し、現在地付近の予定を追加します。今の時刻を含むように開始時刻と滞在時間を設定してください。
2. 宿を追加し、チェックイン可能時刻を設定します。次の予定の時刻を守りたい場合は、その予定の開始時刻を固定します。
3. 「いまどうする？」で「疲れた」「荷物が重い」などを選び、疲れの強さを設定して検索します。
4. 徒歩時間・休める時間と、案の経路や確認情報を比較します。閲覧・選択だけでは元の旅程は変わりません。
5. 案を選び、「この案で旅程を確認」から追加・未定への移動・時刻の変更を確認します。「この内容で旅程に入れる」で確定すると、元の固定予定を保ちながら旅程に反映されます。
6. 反映直後の通知にある「元に戻す」から、今回の変更をまとめて取り消せます。

京都の例は、現在の予定を京都駅、宿をホテルグランヴィア京都、次の固定予定を17:00の夕食とすると、仕様書の画面と対応させて確認できます。Simulatorで確認する場合は、位置情報も京都駅付近へ設定してください。場所の候補と所要時間は、現在地・時刻・通信状況によって変わります。

次の固定予定がない場合も利用できます。まだ先のチェックイン時刻があればその時刻まで、どちらもなければ30分〜5時間の範囲で過ごす時間を選んで案を比較します。

### 宿の情報を検索AIで確認する場合（追加設定）

宿のチェックイン前の荷物預かりなどの公開情報は、別途中継サーバーを設定すると検索AIで確認できます。場所の候補と経路はMapKit、案の組み立てと時間計算はSwift側が担当します。中継がない場合、宿の荷物預かり情報は未確認として扱います。

中継はTypeScript／Cloudflare Workers／D1で実装しています。ローカル実行にはNode.js・npmと、ご自身のPerplexity APIキーが必要です。

```sh
cd server/relay
npm ci
cp .dev.vars.example .dev.vars
```

`.dev.vars` の `PERPLEXITY_API_KEY` にキーを設定し、続けて次を実行します。ローカルでは `APP_TOKEN` を設定しないでください。

```sh
npm run db:local
npm run dev
```

iPhone Simulatorは `http://localhost:8787` に接続します。アプリで場所を指定した宿を追加し、情報確認の説明シートで「わかった」を選ぶと、宿の公式案内・出典・確認日を確認できます。案内がある場合も、当日の受付状況・空席・待ち時間を保証するものではありません。

実機でAI確認を行う場合は、ご自身の公開中継のURLとアプリ用トークンを `server/relay/Relay.plist.example` の形式で `Romy/Config/Relay.plist` に設定します。通常の旅行・旅程機能を試すだけなら、この設定は不要です。APIキーや実際の接続設定はリポジトリに含めていません。

## 出典・ライセンス

旅行名から「すべての旅行」を開き、下部の「出典・ライセンス」へ進めます。旅行未作成時は初回画面からも開けます。

フォントの著作権表示・OFL全文、使用データの提供元・加工内容、観光地2,500件の元記事一覧を同梱しています。元記事一覧は記事名・Wikidata IDで検索できます。本文と一覧はオフラインで閲覧でき、外部サイトを開く際に通信します。

## ソース構成

| 場所 | 内容 |
| --- | --- |
| `Romy/Features/` | SwiftUIの画面・画面遷移 |
| `Romy/Domain/` | 旅程・時間計算、過ごし方の案、反映・取り消し |
| `Romy/Models/` | SwiftDataの旅行・予定・行きたい場所 |
| `Romy/Search/` | MapKit検索・経路、画像、検索AI中継との接続 |
| `Romy/Resources/` | フォント、検索データ、出典表示 |
| `RomyTests/` | 計算・状態・反映・データ読み込みなどの単体テスト |
| `server/relay/` | 検索AI中継と、そのテスト |
| `Tools/sights/` | Pythonによる観光地データの整備 |
| `docs/` | 簡易仕様書・画面画像・データの出典記録 |

## 検証

XcodeのTestから単体テストを実行できます。コマンドで実行する場合は、利用可能なSimulatorを指定してください。

```sh
xcodebuild test -project Romy.xcodeproj -scheme Romy \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max' \
  -only-testing:RomyTests CODE_SIGNING_ALLOWED=NO
```

中継サーバーは次のコマンドで確認できます。

```sh
cd server/relay
npm test
npm run typecheck
```
