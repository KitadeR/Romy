# 矛盾判定の見直し（2026-11-19）

本番反映後、Simulatorで提案されたカフェ2店と[確認用の店](holdout-2026-11-19.md)の多くが、AIの `conflicting=true`（出典が食い違う）で未確認になりました。確認用の8件を見ながら直さないよう、別に「調べる用」の京都の6店（FUKUNAGA901、塩小路カフェ、六曜社珈琲店、スマート珈琲店、喫茶ソワレ、進々堂 寺町店）で原因を分類しました。調べる用の店の検索結果と回答はリポジトリに含めていません。

## 原因

- **確認できないことと矛盾の混同:** 指示文が「店舗・対象日を確認できなければ空文字にし、conflicting=true」としていた。公式ページがない店も「矛盾」と答え、診断が実態と合わなかった。
- **公式でないページとの違い:** 食べログ・口コミ・地図との違いでも矛盾と答えていた。公式でないページの候補はもともと採用しないため、これらとの違いは判定に関係しない。
- **営業時間の一部の時間帯:** スマート珈琲店の公式ページの「営業時間 8:00〜19:00」と「2F ランチタイム 11:00〜14:30」を両方選び、コードが区間の重なりとして矛盾にしていた（AIの判定は矛盾なし）。
- **公式の判定:** 六曜社でnote.comの個人ブログが公式と判定され、確認済みになっていた（見直し前から）。

## 変更

- `conflicting` は公式ページ同士で対象日の営業時間・休業が食い違うときだけにする。確認できないことは矛盾にしない。
- ランチタイム・モーニング・テイクアウトなど、営業時間の中の一部の時間帯の候補は選ばせない。
- 個人ブログ（note・アメブロ・はてな）と地図・まとめ記事（ナビタイム、るるぶ、ことりっぷ、icottoなど）を公式でないサイトの一覧に加える。この一覧は公式の判定を外すだけで、与えることはない。
- 「'26/10/19(月)」のアポストロフィつき2桁の年を読む。月日として成り立たない「26/10」は日付として使わない。

## 結果

調べる用の6店（各2回）：スマート珈琲店が公式ページから8:00〜19:00で確認できるようになった。ほかの店は公式ページがなく、診断が「矛盾」から「公式出典なし」に変わった。進々堂 寺町店は2回中1回、公式でないページ同士の違いで矛盾と答えた。

| | 公式案内と一致 | 確認済みなのに不一致 |
| --- | ---: | ---: |
| 調整に使ってきた12件×3回 | 17/36（前回18/36） | 0 |
| 確認用の8件×3回（変更後に1回だけ） | 6/24（前回3/24） | 0 |

確認用の8件では天下一品 総本店（11:00〜翌1:00）が確認できるようになった。公式同士が食い違うポルタ支店・京都駅店（12件側）は未確認のまま。

## 限界

- 2桁の年の不具合は、確認用の8件の結果（天下一品の臨時休業でAIは正しく休業と答えたが、コードが日付を読めなかった）から見つけた。休業の書き方については、確認用の店も調整に使ったことになる。
- 2桁の年を直した後の再測定は、Workers AIの1日の無料枠（10,000 Neuron）を評価で使い切ったため完了していない。評価Workerは本番と同じアカウントの枠を使うため、この日は本番の読み取りもリセットまで失敗した。評価の回数は事前に見積もる。
- 東華菜館は、AIが土日祝の営業時間を選び、コードが採用せず未確認になった。誤った確認ではないが、平日・土日の区別はAIに依存している。
- 調べる用の店は6店・各2回、確認用の店は8件・各3回の少数の計測。
